# 专家提示词与知识范围

所有资料继续存入同一个 SQLite documents 表，范围记录在文档 JSON 的 scope 字段中。

| scope | 检索范围 |
| --- | --- |
| shared | 两位专家共用 |
| palace | 宫廷证据评审专家专属 |
| technical | 技术方案评审专家专属 |

宫廷专家的会话角色为 evidence，技术专家为 architecture。服务端在本地演示和所有模型适配器入口过滤资料，检索工具每轮只收到公共和当前专家专属资料。这个分类用于控制专家检索，不是企业用户权限系统。

两页知识库面板均支持上传前选择范围，以及修改已有资料范围。旧上传缺少 scope 时按公共资料处理，可手动分类。内置证据指南按宫廷资料处理，其余三份内置演示资料按技术资料处理；不会覆盖已有内容。

角色身份、发言风格和行为规则保存在 server/expert-prompts.mjs，而不是从知识文档执行。两位专家共用事实核查、引用校验、澄清与简短发言规则，并分别采用证据评审和技术评审提示词。提示词作用于真实模型调用；无模型时仍是有限的本地规则演示。

资料上传接口 POST /api/documents 接收 title、content 和可选 scope（默认 shared）；PATCH /api/documents/:id 只修改 scope。

修改后需重启后端。使用 npm start 的生产模式还需要先运行 npm.cmd run build，随后刷新页面。
