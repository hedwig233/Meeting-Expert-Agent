# ContextOps · 我的会议任务

导入会议纪要，使用 GPT 整理与本人相关的任务，再按需要邀请专家分析具体任务。任务提取和专家回答均通过后端 Responses API 请求当前配置的模型，不使用预设回答。

## 运行

```powershell
cd D:\Project\ops-context-agent
python -u server.py
```

浏览器访问 <http://localhost:5175>。

## 使用流程

1. 点击“导入会议纪要”，填写纪要中使用的本人姓名，粘贴文本或选择 `.txt` / `.md` 文件。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030，文本最多 30,000 字，文件最多 200 KB。
2. 点击“提取我的任务”。GPT 整理本人负责、协作以及分工待确认的安排，显示负责人、原文中的截止时间、明确写出的优先级与原文依据。请核对提取结果；没有明确关联本人的任务时，会显示空结果。
3. 点击任务标题切换当前讨论任务；可以勾选已完成，或直接记录任务问题。
4. 需要协助时，点击该任务的“请专家协助”，选择推荐专家、其他领域专家或自定义角色。添加专家只载入当前上下文并准备提问，不自动调用 GPT。
5. 在讨论区发送 `@专家名 问题`，专家才会结合原始纪要、任务信息和最近的讨论回答。取消当前任务选择后，可以讨论整份纪要。
6. 右侧“分析与回答”可搜索当前专家的任务、问题、回答、参考依据和建议动作。每次提问独立记录，失败后可以重试。

仅输入 `@` 时显示成员提示，角色名以蓝色高亮。普通消息和 `@真人成员` 只在页面内记录，不调用 GPT，也不发送外部通知。

## 模型配置

`model-config.json` 默认使用 `gpt-6.1-sol`，接口地址为 `https://api.openai-next.com/v1`（第三方兼容网关），请求路径为 `/responses`。

服务端优先读取 `OPENAI_API_KEY` 环境变量，也支持读取 Windows 用户/系统环境变量；未设置时，读取本机 `%USERPROFILE%\.codex\auth.json` 中的 `OPENAI_API_KEY`。设置 `CODEX_HOME` 可以更改该目录。密钥只在服务端读取，不发送给浏览器。

可用 `OPENAI_BASE_URL` 和 `OPENAI_MODEL` 环境变量覆盖项目配置。修改后端代码或进程环境变量后需要重新启动服务。

## 数据与功能边界

- 提取任务时会将纪要与本人姓名发送给所配置的 GPT 服务；向专家提问时还会发送任务与相关讨论。页面提供原文依据供核对，模型输出仍可能有误。
- 纪要、任务完成状态、讨论和专家记录只保存在当前页面内存中，刷新后需要重新导入。只有显示偏好保存在本地。
- 重新提取成功后会替换当前任务、讨论与专家记录；提取失败保留原工作台。点击“清空工作台”会清除当前会话。
- 专家为可选步骤，不会自动加入或主动回答。建议动作仅支持预览和模拟确认，不修改外部系统。
- 右上角可拖动调整字号、切换主题，默认高对比主题和微软雅黑。桌面端任务与专家面板等高，内容超出后内部滚动。
