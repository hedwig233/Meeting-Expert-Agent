# 组件来源与沿用说明

| 组件 / 能力 | 来源 | 使用方式与归属 |
| --- | --- | --- |
| 原会议专家 Demo 基础 | 本工作区已有的 `ops-context-agent` 项目 | 沿用前端页面基础、会议讨论/专家角色及后端模型代理，改造为纪要任务流程；赛前版本、原作者与授权范围待团队确认 |
| 本次改动 | 当前工作区的代码迭代 | 新增纪要导入、个人任务提取、任务上下文、原文校验、布局调整与交付材料；使用 AI 编程助手辅助完成，团队需复核并负责最终提交 |
| 模型能力 | 配置的 `gpt-6.1-sol` 服务 | 通过第三方兼容网关调用，基础模型不是团队自研；实际模型权限与服务可用性由账号提供方决定 |
| API 网关 | https://api.openai-next.com/v1 | 项目当前默认的第三方 Responses 兼容接口；不是项目自建网关 |
| Python 运行时及标准库 | Python Software Foundation，https://www.python.org/ | `http.server`、`urllib`、`json` 等；遵循 Python 随附的 PSF 许可 |
| 浏览器原生 API | HTML / CSS / JavaScript、File API、TextDecoder、Fetch | 无前端框架、npm 运行依赖和 CDN 依赖 |
| 系统字体 | Microsoft YaHei 等客户端已安装字体 | 通过 CSS 引用，交付包不分发字体文件；无该字体时使用系统替代字体 |
| 浏览器自动化（可选开发工具） | Microsoft Playwright，https://github.com/microsoft/playwright-python | 用于交互验证与录屏，Apache-2.0；不属于应用运行依赖 |
| 视频转码（可选制作工具） | imageio-ffmpeg，https://github.com/imageio/imageio-ffmpeg；FFmpeg，https://ffmpeg.org/ | 使用临时安装的转码工具将 WebM 转为 MP4；工具不随源码包分发，也不是应用运行依赖。imageio-ffmpeg 采用 BSD-2-Clause，FFmpeg 依构建采用 LGPL/GPL，遵循所用构建的许可 |
| Docker 基础镜像（可选） | Docker Official Image `python:3.11-slim`，https://hub.docker.com/_/python | 用于可选容器启动；遵循镜像内各组件许可，当前机器未验证容器构建 |
| 演示纪要 | 项目提供的虚构文本 `examples/meeting-demo.txt` | 仅供演示，不使用实际会议、客户或其他个人资料 |
| 演示视频与截图 | 通过当前应用实际运行录制 | 真实模型调用的可见交互；不包含开发者认证文件或 API key |

当前目录没有项目整体开源许可证，也没有可核对的历史仓库信息。本说明不替原有代码授予新的许可；公开发布与赛前代码沿用范围需团队确认后填写。
