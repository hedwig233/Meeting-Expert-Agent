# 演示脚本

## 演示目的

展示完整路径：导入会议纪要 → 确认我的任务 → 按需邀请专家 → @ 提问 → 搜索分析记录。

随包视频为无旁白的字幕演示，使用虚构纪要，真实调用配置的模型。视频长度、分辨率和文件摘要以 `验证记录.md` 和 `video-metadata.json` 的实际记录为准。重新录制的模型输出与耗时可能不同。

## 讲解稿与操作

| 环节 | 操作 | 可直接使用的讲解 |
| --- | --- | --- |
| 开场 | 展示空工作台 | 这是 ContextOps。我们关注的是会议之后，每个人能否快速确认自己的任务，并解决执行中的专业问题。 |
| 导入 | 导入示例文本，姓名填周宁，点击提取 | 我导入一份纪要，告诉系统我是谁。GPT 会整理我负责、协作和分工待确认的安排。 |
| 核对 | 查看任务负责人、时间、展开原文 | 每项任务都带原文依据。别人的任务和已经完成的事项不应作为我的新待办，含糊分工会保留待确认状态。 |
| 专家 | 选中迁移验收任务，添加数据库专家 | 不是所有任务都需要专家。遇到验收问题时，我再邀请数据库专家。加入时只准备上下文，不主动生成回答。 |
| 提问 | 输入 @，选择专家后发送问题 | 只有显式提问才调用模型。专家结合这份纪要和选中的任务，给出验收关注点、缺少的信息和下一步建议。 |
| 记录 | 查看回答、搜索验收、滚动右侧 | 回答关联具体任务，可以搜索历史问题和分析。参会专家和搜索框固定在上方，便于持续查找。 |
| 收尾 | 勾选一项任务完成 | 从纪要到个人行动，再到按需专业协助，这就是我们实现的完整交互。当前是页面会话原型，刷新后需要重新导入。 |

## 重新录制

应用正常启动且模型可用后，在项目根目录执行：

```powershell
python -m pip install playwright
python -m playwright install chromium
python tools/record_demo.py
```

脚本默认使用已安装的 Edge；如果没有 Edge，可以使用 `python tools/record_demo.py --browser chromium`。视频会实际请求模型，消耗两次请求额度（一次提取、一次回答）。脚本不读取或展示密钥，失败时停止并报告错误，不会替换为模拟回答。录制脚本输出 WebM；随包 MP4 由该 WebM 转换，转码工具不是运行应用的依赖。

脚本默认录制本机 http://localhost:5175，可用 `--url` 指定已启动的项目服务。可直接用 `docs/演示材料.html` 播放随包视频；该文件应与视频放在同一目录。

需要生成 MP4 时，可安装可选的转码工具后执行：

```powershell
python -m pip install imageio-ffmpeg
python tools/transcode_demo.py
```

也可以已有 FFmpeg 的路径作为 `--ffmpeg` 参数传入。此步骤只转码，不裁剪模型等待过程，不添加或替换模型回答。
