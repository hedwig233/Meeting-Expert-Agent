## 推荐提交内容

提交 `dist/ContextOps-交付包.zip`；如平台分栏上传，分别提交 `项目介绍.md`、`代码与运行说明.md`、演示视频和仓库地址。包内 `docs/演示材料.html` 可播放同目录视频并查看截图。

填写以上待确认项后，重新运行 `python tools/package_submission.py`，确保压缩包与最终材料一致。打包脚本只收集项目白名单文件，不包含 `.env`、本机认证文件、缓存或临时日志。
