# 订单服务接口契约 · 示例 v1.2

本文件为虚构的演示资料，非任何公司的真实接口。

## 创建订单 POST /orders
当前示例接口不支持幂等。每次合法请求均可能创建一个新的订单。客户端因网络超时未收到响应，并不意味着服务端未创建订单。禁止在未确认订单状态时直接自动重试创建请求。

请求字段包括 customerId、items、clientRequestId。当前 clientRequestId 仅用于日志关联，不提供唯一性约束，不能作为已实现幂等的证据。

## 查询订单 GET /orders/status
支持使用 clientRequestId 查询创建结果。查询可能存在短暂延迟；未查到订单时不能立即认定创建失败。

## 后续版本规划
计划增加幂等键与服务端去重，但本文件不表示该能力已经上线。上线状态应由当前版本的实现和测试证明。
